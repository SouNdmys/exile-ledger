# POE Ninja Data

一个人自己用的 PoE2 小工具,Windows 桌面程序。做两件事:

- **蹲价** —— 你在交易网站上把条件筛好,把那条搜索的网址粘进来。程序替你反复去看,
  价格掉到你设的上限以内,屏幕角上就弹一张卡片,还会响一声。
- **看热度** —— 从 poe.ninja 上抓一批热门 BD 的角色,统计他们身上**最常穿的暗金**和
  **最常见的词缀**,顺便拼上参考价。

两件事互不打扰:不粘搜索,热度榜照样能看;不看热度,蹲价照样跑。

---

## 怎么跑起来

编一次(需要装好 Rust 和 Windows SDK),在仓库根目录:

```
powershell -ExecutionPolicy Bypass -File scripts\build-release.ps1
```

它做两件事:编出 `target\release\pnd-app.exe`,然后在**桌面**放一个
「POE Ninja Data」快捷方式。以后就双击那个快捷方式,不用再开命令行。

exe 换了地方(比如仓库搬盘)之后,不用重编,只要重刷快捷方式:

```
powershell -ExecutionPolicy Bypass -File scripts\make-shortcut.ps1
```

程序不会自己开机启动,想跑就双击,不想跑就关掉。

---

## 第一次打开

去**设置**页,从上往下三步:

1. **联赛** —— 填当前赛季名,比如 `Forbidden Rites`。
2. **登录官网** —— 按这个按钮会单独开一扇窗,里面是官网自己的登录页面。
   **密码只进那个页面,不经过本程序**;登录成功后程序只读走 `POESESSID` 这一个
   cookie,窗口自己关掉。
   (没有 WebView2 的话按钮旁会提示,点「去装 WebView2」装一下:
   <https://developer.microsoft.com/microsoft-edge/webview2/>)
3. **测试会话** —— 拿存下来的 cookie 真发一次搜索,确认交易站认它。
   这一下会花掉 6 小时额度里的一次,所以它是个按钮而不是自动跑的。

最后按**保存**。

会话不是必需的:**轮询不用登录也能跑**。只有「Live 秒推」和「去藏身处」这两样要它。

---

## 加一条搜索

在**蹲价**页上方的表单里:

- **搜索 URL 或 id** —— 从浏览器地址栏整条粘进来即可。
- **备注名** —— 你自己看的名字,比如「风暴合唱」。
- **联赛** —— 留空就用设置页那个。
- **价格上限** + **货币** —— 价格 **≤** 上限就算命中(等于也算)。
- **Live 秒推** —— 开了就再挂一条 WebSocket,新挂单几乎是立刻推过来;需要会话。
  秒推连上之后轮询会自动放慢,这是正常的,状态列会写「秒推中」。

**要改已有的一条**:在表格里点中那一行,上面的表单就变成「正在改「XX」」,
改完按保存。唯独**搜索本身改不了** —— 想让它盯别的东西,就删掉重新粘一条。

## 卡片上的四个按钮,和那条红线

弹出来的提醒卡片上有:**打开交易页** / **复制私聊** / **去藏身处** / **忽略**。
每一条在**提醒记录**页里也有一份,过后还能补按。

**这条红线不会破**:程序永远不往游戏里发按键、发鼠标。它不会自动私聊、不会自动
传送。「复制私聊」只是把那句话放进剪贴板,**贴到游戏里的是你自己**;「去藏身处」
是走交易站官方的接口,而且**每一次都要你亲手点一下**。一次点击 = 一个动作,没有
后台替你做的事。

---

## 它多久看一次

交易站会在每次回应里告诉程序「还剩多少额度」。程序只按其中的 **50%** 花,
不贴着上限跑 —— 留一半给你自己开网页用,也免得被判成机器人。

于是真正的节奏是「你设的间隔」和「额度算出来的地板」两者取大:搜索条数越多,
地板越慢(默认额度下,1 条约 73 秒,2 条约 145 秒,3 条约 217 秒)。
设置里的间隔建议填 **90–180 秒**,再小也会被地板顶回去。

---

## poe.ninja 那两页

**暗金热度**和**词缀热度**共用同一批采样数据。第一次打开是空的,按一下**刷新**。

刷新一轮的代价:默认采 **2000 个角色**,**每秒 1 个请求**,大约 **35 分钟** 跑完。
跑的时候你可以照常用别的页面。同一个联赛 **24 小时内不会重采**,所以关掉程序再打开
不会又来一遍;想提前重来就再按刷新。

## 东西都存在哪儿

全在这一个文件夹里:`%LOCALAPPDATA%\PoeNinjaData\`
(地址栏直接粘这一串就能打开)

| 文件 | 是什么 |
| --- | --- |
| `settings.json` | 你在设置页填的一切,**包括明文的 POESESSID** |
| `watch.sqlite` | 搜索列表、轮询状态、提醒历史 |
| `ninja.sqlite` | poe.ninja 的采样缓存(两张热度榜读它) |
| `app.log` | 运行日志,程序关掉之后还查得回来 |
| `panic.log` | 程序崩了才有。有这个文件就说明上次是崩的 |
| `webview2\` | 登录窗那个浏览器内核自己的 cookie 和缓存。登录出问题就把它整个删掉 |

界面右上角有个**日志**按钮,拉开是个抽屉,里面就是 `app.log` 的实时内容,
旁边的**复制**能一键拷走。出了问题先看这里。

## 出问题了

- **「交易站不认这个 POESESSID」** —— cookie 过期了。回设置页按「登录官网」重来一次。
  轮询会自动退回匿名模式继续跑,不会停。
- **「秒推停用:没有会话」** —— Live 开着但没有有效 cookie。同上,登录一次即可。
- **「去藏身处:失败 HTTP 403」** —— 交易站的 `hideout_token` 只活 5 分钟。程序发现它
  太老会自己重新抓一张再发一次,**这一步是自动的**,你不用管。两次都不成才会报错。
- **「Cloudflare 把交易站拦住了」** —— 上游的防护墙临时挡了一下。程序会自己停到提示
  的那个时间点再继续,什么都不用做。等就是了。
- **登录窗打不开** —— 这台机器缺 WebView2。按「去装 WebView2」,或者用浏览器登录后从
  开发者工具 → Application → Cookies → pathofexile.com 里把 `POESESSID` 手动粘进设置页。
- **程序一闪就没了** —— 去看 `%LOCALAPPDATA%\PoeNinjaData\panic.log`。

## 给好奇的人:探针

几个命令行小程序,用来单独试某一条链路(调用的是和界面完全同一份代码):

```
cargo run -p pnd-runtime --bin trade_probe -- --league "Forbidden Rites" --search <搜索URL> --cap 20 --currency divine --rounds 3
cargo run -p pnd-runtime --bin ninja_probe -- --search --class "Gemling Legionnaire"
cargo run -p pnd-platform-win --bin alert_probe -- --corner bottom_right --auto-hide 1
```
